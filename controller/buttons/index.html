Manual & help

Disconnect all controllers from the Wireless Receiver before connecting.

Bluetooth is required

This page configures the receiver over Bluetooth. A computer without Bluetooth cannot connect to it.

  1. Check the computer. It needs Bluetooth: built in, or a USB Bluetooth adapter on desktops without it.
  2. Use Chrome or Edge — desktop or Android. Safari on iPhone / iPad has no Web Bluetooth and cannot open the receiver.
  3. Turn Bluetooth on in the system settings (Windows: Settings → Bluetooth & devices; macOS: Control Centre) and allow the browser prompt when it appears.
  4. Prepare the receiver: power it, unplug any controllers, and press the pairing button until the LED blinks.
  5. Click Select Device and pick the entry starting with BlueRetro_.

Still empty? Close other apps that use Bluetooth, move closer, reload the page and try again. Read the full guide

Edit mappings entry by entry — for fine tuning, fixing one game, or tweaking a few buttons on top of a preset.

  1. Pick the layer and controller number first (beginners: Global, device #1).
  2. Source / Destination choose the device type, which decides the button names available per row.
  3. For each row, set Source (controller button) and Destination (console button).
  4. Press Save Mappings to write; Add Mapping appends an entry.
